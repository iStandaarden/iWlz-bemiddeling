# CIZ

Hier staan de query templates die het CIZ kan gebruiken voor het raadplegen van gegevens in het Bemiddelingsregister. 
De templates dienen als voorbeeld hoe de query opgebouwd moet worden. De structuur en bepaalde verplichte parameters zijn nodig om te voldoen aan de autorisatie-policies.

Ga naar [Raadplegen](/raadplegen/) voor meer uitleg.
